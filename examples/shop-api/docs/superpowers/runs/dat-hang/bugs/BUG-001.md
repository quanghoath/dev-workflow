# BUG-001 · Double-click nút "Đặt hàng" tạo 2 đơn

- **Phát hiện ở:** P4 · kịch bản `UI-2` · AC liên quan: `AC-1`
- **Mức:** fail
- **Trạng thái:** fixed · loop 1/3

## Tái hiện

1. Mở `/cart` với 2 sản phẩm.
2. Dùng `evaluate_script` bấm nút "Đặt hàng" 2 lần liên tiếp (cách nhau ~50 ms).

**Mong đợi:** 1 request `POST /api/orders`, 1 đơn.
**Thực tế:** 2 request, 2 đơn `PENDING`, tồn kho bị trừ 2 lần.
**Bằng chứng:** `evidence/ui-2-network.md` (danh sách network từ `list_network_requests`).

## Nguyên nhân gốc

Nút được khoá bằng state `isSubmitting`, nhưng state chỉ cập nhật ở lần render sau. Lần bấm thứ hai đến trước khi render nên handler vẫn chạy. API cũng không chống trùng nên nhận cả hai.

## Sửa

- Test tái hiện: `CartPage.test.tsx::không gửi 2 request khi bấm liên tiếp` (đỏ trước khi sửa, xanh sau khi sửa).
- Thay đổi:
  - `src/cart/CartPage.tsx`: khoá bằng `useRef` ngay trong handler, trước `await`.
  - `OrdersController`: nhận header `Idempotency-Key`; cùng key trong 10 phút trả lại đơn đã tạo.
- Đã chạy lại: `UI-2` → pass; toàn bộ P4 (hồi quy) → pass.
